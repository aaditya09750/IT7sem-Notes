NUMERICAL TYPE 1: CONFUSION MATRIX & PERFORMANCE METRICS EVALUATION
--------------------------------------------------------------------------------
Standard 10-Mark Question (Repeated in May 2024, Nov 2024, Dec 2023)

Sample Problem Template (May 2024):
  +----------------------+--------------------+--------------------+
  |                      | Actual Legitimate  | Actual Fraudulent  |
  +----------------------+--------------------+--------------------+
  | Predicted Legitimate |       850 (TN)     |         30 (FN)    |
  | Predicted Fraudulent |        20 (FP)     |        100 (TP)    |
  +----------------------+--------------------+--------------------+

Formulas & Calculations:
  • Total Samples = 850 + 30 + 20 + 100 = 1000
  • TP = 100, TN = 850, FP = 20, FN = 30
  • Accuracy    = (TP + TN) / Total = (100 + 850) / 1000 = 950 / 1000 = 0.95 (95%)
  • Precision   = TP / (TP + FP) = 100 / (100 + 20) = 100 / 120 = 0.833 (83.33%)
  • Recall      = TP / (TP + FN) = 100 / (100 + 30) = 100 / 130 = 0.769 (76.92%)
  • Sensitivity = Recall = 76.92%
  • Specificity = TN / (TN + FP) = 850 / (850 + 20) = 850 / 870 = 0.977 (97.70%)
  • F1-Score    = 2 * (Precision * Recall) / (Precision + Recall)
                = 2 * (0.833 * 0.769) / (0.833 + 0.769) = 1.281 / 1.602 = 0.7996 (~80%)

NUMERICAL TYPE 2: BAYES' THEOREM MEDICAL TEST POSTERIOR PROBABILITY
--------------------------------------------------------------------------------
Standard 5-Mark Question (Repeated in Dec 2025 Q.1f)

Problem Statement:
  A medical test is 99% accurate (gives correct results 99% of time). Disease affects 1 in 10,000 people.
  Calculate the probability that a person who tests positive actually has the disease.

Step-by-Step Solution:
  • Let D = Person has disease, ~D = Person is healthy.
  • Let + = Test is positive.
  • Given:
      - Prior Probability: P(D) = 1/10,000 = 0.0001
      - P(~D) = 1 - 0.0001 = 0.9999
      - Sensitivity: P(+ | D) = 0.99
      - False Positive Rate: P(+ | ~D) = 1 - 0.99 = 0.01
  • Total Probability of testing positive P(+):
      P(+) = P(+ | D)*P(D) + P(+ | ~D)*P(~D)
           = (0.99 * 0.0001) + (0.01 * 0.9999)
           = 0.000099 + 0.009999 = 0.010098
  • Posterior Probability P(D | +):
      P(D | +) = [ P(+ | D) * P(D) ] / P(+)
               = 0.000099 / 0.010098 = 0.009804 (approx 0.98%)
  • Interpretation: Even with a 99% accurate test, because the disease is extremely rare,
    a positive test result only gives a ~0.98% chance of actually having the disease (due to false positives dominating).

NUMERICAL TYPE 3: FUZZY SET OPERATIONS (ALGEBRAIC & BOUNDED)
--------------------------------------------------------------------------------
Standard 5-Mark Question (Repeated in Nov 2024 Q.1b)

Problem Statement:
  A = 0.3/1 + 0.4/2 + 0.5/3 + 0.6/4
  B = 0.1/1 + 0.2/2 + 0.2/3 + 0.1/4

Formulas & Step-by-Step Solution:
  1. Algebraic Sum (mu_{A + B}(x) = mu_A(x) + mu_B(x) - mu_A(x)*mu_B(x)):
     • x=1: 0.3 + 0.1 - (0.3*0.1) = 0.4 - 0.03 = 0.37
     • x=2: 0.4 + 0.2 - (0.4*0.2) = 0.6 - 0.08 = 0.52
     • x=3: 0.5 + 0.2 - (0.5*0.2) = 0.7 - 0.10 = 0.60
     • x=4: 0.6 + 0.1 - (0.6*0.1) = 0.7 - 0.06 = 0.64
     => A + B = 0.37/1 + 0.52/2 + 0.60/3 + 0.64/4

  2. Algebraic Product (mu_{A . B}(x) = mu_A(x) * mu_B(x)):
     • x=1: 0.3 * 0.1 = 0.03
     • x=2: 0.4 * 0.2 = 0.08
     • x=3: 0.5 * 0.2 = 0.10
     • x=4: 0.6 * 0.1 = 0.06
     => A . B = 0.03/1 + 0.08/2 + 0.10/3 + 0.06/4

  3. Bounded Sum (mu_{A (+) B}(x) = min(1, mu_A(x) + mu_B(x))):
     • x=1: min(1, 0.3 + 0.1) = 0.4
     • x=2: min(1, 0.4 + 0.2) = 0.6
     • x=3: min(1, 0.5 + 0.2) = 0.7
     • x=4: min(1, 0.6 + 0.1) = 0.7
     => A (+) B = 0.4/1 + 0.6/2 + 0.7/3 + 0.7/4

  4. Bounded Difference (mu_{A (-) B}(x) = max(0, mu_A(x) - mu_B(x))):
     • x=1: max(0, 0.3 - 0.1) = 0.2
     • x=2: max(0, 0.4 - 0.2) = 0.2
     • x=3: max(0, 0.5 - 0.2) = 0.3
     • x=4: max(0, 0.6 - 0.1) = 0.5
     => A (-) B = 0.2/1 + 0.2/2 + 0.3/3 + 0.5/4

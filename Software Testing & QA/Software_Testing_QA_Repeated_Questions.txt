TOPIC: White-Box Testing: DD-Graph, Cyclomatic Complexity & Independent Paths
--------------------------------------------------------------------------------
Marks: 10 Marks
Total Appearances: Both Papers
Appeared in:
  • QP Code: 15346 (Q.4b - Prime Number Program)
  • QP Code: 28365 (Q.2a - Factorial Program with sub-function `fact()`)
  • QP Code: 28365 (Q.4a - Graph Metrics Definition & Region Method)

Exact Question Variations:
"Consider following C code. Draw DD graph, Calculate cyclomatic complexity using all methods, List out independent paths and design test cases."

What Examiners Look For:
  • Construction of Control Flow Graph (CFG) / Decision-to-Decision (DD) Graph with labeled nodes and directed edges.
  • Calculation of Cyclomatic Complexity V(G) using 3 Methods:
      1. Formula 1: V(G) = E - N + 2P (where E = edges, N = nodes, P = connected components = 1).
      2. Formula 2: V(G) = P_nodes + 1 (where P_nodes = count of predicate/decision nodes).
      3. Formula 3: V(G) = Total Enclosed Regions + 1.
  • Independent Basis Paths Enumeration (e.g. Path 1: 1-2-3-4-13-14-15, Path 2: ...).
  • Test Case Table (Test Case ID, Input Values, Expected Output, Path Covered).

RANK 3 [APPEARED IN 100% OF QUESTION PAPERS]
TOPIC: Mutation Testing (Primary vs Secondary Mutants, Score & Mutant Killing)
--------------------------------------------------------------------------------
Marks: 10 Marks (and 5M)
Total Appearances: Both Papers
Appeared in:
  • QP Code: 15346 (Q.1b - 5M)
  • QP Code: 28365 (Q.5a - 10M)

Exact Question Variations:
"What is Mutation Testing? Differentiate between primary and secondary mutants. Explain primary mutant with an example."

What Examiners Look For:
  • Definition: Fault-based white-box testing technique where deliberate small syntactic changes (mutants) are injected into the source code to evaluate test suite adequacy.
  • Primary Mutant: Mutant generated by applying a single mutation operator once (e.g. changing `+` to `-`).
  • Secondary / Higher-Order Mutant: Mutant created by applying multiple mutation operators simultaneously.
  • Mutation Operators: Arithmetic operator replacement (`+` to `*`), Relational operator replacement (`>` to `>=`), Logical connector replacement (`&&` to `||`).
  • Mutation Score Formula:
      Mutation Score = [ D / (N - E) ] * 100%
      (where D = Killed Mutants, N = Total Mutants Generated, E = Equivalent Mutants).

TOPIC 1: Software Testing Terminology Distinctions
--------------------------------------------------------------------------------
Marks: 5 Marks
Appeared in: QP Code: 15346 (Q.1a)

Key Definitions to Write:
  • Error (Mistake): A human action that produces an incorrect result (e.g. developer misinterprets requirement).
  • Fault / Defect / Bug: A flaw or imperfection in a software component that can cause the component to fail to perform its required function.
  • Failure: The deviation of software from its expected delivery or service at runtime (manifestation of a defect).
  • Testware: All testing artifacts produced during testing (test cases, test scripts, test data, test plans).
  • Test Oracle: A mechanism or standard against which a tester can compare the actual output with the expected outcome.

NUMERICAL 1: DEFECT SPOILAGE CALCULATION (10 MARKS)
--------------------------------------------------------------------------------
Given Data (QP Code: 15346 Q.2a):
  +-------------------+----------------+------------+-------------------------+
  | SDLC Phase        | No. of Defects | Defect Age | Weighted Defects (D * A)|
  +-------------------+----------------+------------+-------------------------+
  | Requirement Specs.|       34       |     2      |       34 * 2 =  68      |
  | HLD               |       25       |     3      |       25 * 3 =  75      |
  | LLD               |       17       |     7      |       17 * 7 = 119      |
  | Coding            |       10       |     8      |       10 * 8 =  80      |
  +-------------------+----------------+------------+-------------------------+
  | TOTAL             |   Sum(D) = 86  |            |   Sum(D * A) = 342      |
  +-------------------+----------------+------------+-------------------------+

Formula & Calculation:
  Defect Spoilage = [ Sum_{i} (Defects Discovered_i * Defect Age_i) ] / [ Total Defects Discovered ]
                  = 342 / 86
                  = 3.9767 (approx 3.98)

Interpretation:
  A higher defect spoilage value indicates defects are staying longer in the lifecycle before detection,
  which exponentially increases rework and defect remediation costs.

NUMERICAL 2: BOUNDARY VALUE ANALYSIS (BVC) & ROBUST TEST CASE DESIGN
--------------------------------------------------------------------------------
Given Range (QP Code: 15346 Q.3a):
  Variables A, B, C in range [1, 100]. Program outputs the minimum number.

Test Case Design Formulas:
  • For n variables:
      - BVC Test Cases = 4n + 1 = 4(3) + 1 = 13 Test Cases.
      - Robust Test Cases = 6n + 1 = 6(3) + 1 = 19 Test Cases.
  • Boundary Points for range [a, b] = [1, 100]:
      - min = 1, min+ = 2, nom = 50, max- = 99, max = 100.
      - Robust boundary points: min- = 0, max+ = 101.

Sample BVC Test Cases (Single Fault Assumption):
  TC1:  (50, 50, 50)  -> Output: 50 (Nominal)
  TC2:  (1,  50, 50)  -> Output: 1  (A = min)
  TC3:  (2,  50, 50)  -> Output: 2  (A = min+)
  TC4:  (99, 50, 50)  -> Output: 50 (A = max-)
  TC5:  (100,50, 50)  -> Output: 50 (A = max)
  TC6:  (50, 1,  50)  -> Output: 1  (B = min)
  ...
  TC13: (50, 50, 100) -> Output: 50 (C = max)

PROGRAM TRACE: PRIME NUMBER DD-GRAPH & CYCLOMATIC COMPLEXITY
--------------------------------------------------------------------------------
Given C Code (QP Code: 15346 Q.4b):
  1.  printf("Enter a number");
  2.  scanf("%d", &number);
  3.  index = 2;
  4.  while (index <= number - 1)
  5.  {
  6.    if (number % index == 0)
  7.    {
  8.      printf("Not a prime number");
  9.      break;
  10.   }
  11.   index++;
  12. }
  13. if (index == number)
  14.   printf("prime number");
  15. // end main

DD-Graph Construction:
  • Node 1: Statements 1, 2, 3 (Sequential block)
  • Node 2: Statement 4 (While loop predicate `index <= number - 1`)
  • Node 3: Statement 6 (If condition `number % index == 0`)
  • Node 4: Statements 8, 9 (Not prime output & break jump to 13)
  • Node 5: Statement 11 (Increment `index++` and loop back to Node 2)
  • Node 6: Statement 13 (If condition `index == number`)
  • Node 7: Statement 14 (Prime number output)
  • Node 8: Statement 15 (End program)

Cyclomatic Complexity Calculations:
  • Decision Nodes (P): Node 2, Node 3, Node 6 => P = 3.
  • V(G) = P + 1 = 3 + 1 = 4.
  • Edges E = 10, Nodes N = 8 => V(G) = 10 - 8 + 2(1) = 4.

Independent Basis Paths (4 Paths):
  • Path 1: 1 -> 2 (False) -> 6 (False) -> 8
  • Path 2: 1 -> 2 (False) -> 6 (True) -> 7 -> 8
  • Path 3: 1 -> 2 (True) -> 3 (True) -> 4 -> 6 -> 8
  • Path 4: 1 -> 2 (True) -> 3 (False) -> 5 -> 2 -> ... -> 8

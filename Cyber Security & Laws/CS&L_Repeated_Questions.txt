RANK 1 [REPEATED IN 5 OUT OF 5 PAPERS - 100% OCCURRENCE]
TOPIC: Buffer Overflow Attacks and Mitigation Strategies
--------------------------------------------------------------------------------
Marks: 10 Marks (and 5M in Short Notes)
Total Appearances: 5 Times
Appeared in:
  • 13/06/2025 (Q.6c - 5M)
  • 25/11/2024 (Q.6c - 5M)
  • 03/01/2024 (Q.3a - 10M)
  • 26/06/2023 (Q.6c - 5M)
  • 19/12/2022 (Q.3a - 10M)

Exact Question Variations:
"Explain different buffer overflow attacks. Also explain how to mitigate buffer overflow attack." (03/01/2024 Q.3a, 19/12/2022 Q.3a, Short notes in other 3 papers)

What Examiners Look For:
  • Stack Frame Architecture: Local variables, Frame Pointer (EBP), Return Address (EIP).
  • Attack Mechanism: Writing beyond allocated buffer boundaries (`strcpy`, `gets`) to overwrite EIP with shellcode pointer.
  • Variations: Stack-based overflow, Heap-based overflow, Format string vulnerabilities.
  • Mitigation Techniques (Must Explain All 4):
      1. Safe Coding: Using bounds-checked functions (`strncpy`, `snprintf`, `fgets`).
      2. Stack Canaries / Cookies: Random values placed before return address verified before function returns.
      3. ASLR (Address Space Layout Randomization): Randomizes stack, heap, and library base addresses.
      4. DEP / NX-Bit (Data Execution Prevention / Non-Executable Stack): Marks stack memory as non-executable.

2. "Explain what is Information Security Standard and Explain HIPAA act in detail." (19/12/2022 Q.6b)

What Examiners Look For:
  • HIPAA (Health Insurance Portability and Accountability Act):
      - Objective: Protect Protected Health Information (PHI) and electronic PHI (ePHI).
      - 3 Core Security Safeguards:
          a. Administrative Safeguards (Security management process, workforce training, access control policies).
          b. Physical Safeguards (Facility access, workstation security, device media controls).
          c. Technical Safeguards (Access control, audit controls, integrity controls, transmission encryption).
      - Privacy Rule vs Security Rule vs Breach Notification Rule.
  • SOX (Sarbanes-Oxley Act):
      - Objective: Protect investors by improving financial reporting accuracy and corporate governance.
      - Key IT Sections: Section 302 (Corporate Responsibility for Financial Reports) & Section 404 (Management Assessment of Internal Controls).
      - IT Audit Requirements: Access logging, change management tracking, disaster recovery, data tampering prevention.

RANK 5 [REPEATED IN 4 OUT OF 5 PAPERS - 80% OCCURRENCE]
TOPIC: SQL Injection (SQLi) Attacks, Lifecycle & Mitigation
--------------------------------------------------------------------------------
Marks: 10 Marks
Total Appearances: 4 Times
Appeared in:
  • 13/06/2025 (Q.3a - 10M)
  • 25/11/2024 (Q.4a - 10M)
  • 03/01/2024 (Q.5a - 10M)
  • 19/12/2022 (Q.6a - 10M)

Exact Question Variations:
"Explain steps for SQL Injection attack. State different countermeasures / How to prevent SQL Injection attacks?"

What Examiners Look For:
  • Vulnerability Root Cause: Direct concatenation of unvalidated user inputs into backend SQL query strings.
  • Attack Steps & Syntax Examples:
      - Tautology / Authentication Bypass: `' OR '1'='1' --`
      - Union-based SQLi: `' UNION SELECT username, password FROM users --`
      - Blind SQLi (Boolean-based & Time-based using `WAITFOR DELAY` or `sleep()`).
  • Prevention & Countermeasures (Must List 4):
      1. Parameterized Queries / Prepared Statements (e.g., `PreparedStatement` in Java, PDO in PHP).
      2. Stored Procedures (Properly parameterized).
      3. Input Validation & Whitelisting.
      4. Principle of Least Privilege for DB user accounts.
      5. Web Application Firewalls (WAF).

--------------------------------------------------------------------------------
STATUTORY BLUEPRINT: IT ACT 2000 (KEY SECTIONS TO MEMORIZE)
--------------------------------------------------------------------------------
1. Section 43: Penalty and compensation for damage to computer systems, downloading data without permission.
2. Section 65: Tampering with computer source documents (Imprisonment up to 3 years or fine up to 2 lakh).
3. Section 66: Hacking with computer systems, fraudulent/dishonest activities.
4. Section 66C: Identity theft using password/electronic signature.
5. Section 66D: Cheating by personation using computer resource.
6. Section 66E: Violation of privacy (capturing/publishing private images without consent).
7. Section 67: Publishing or transmitting obscene material in electronic form.
8. Section 72: Penalty for breach of confidentiality and privacy.

--------------------------------------------------------------------------------
INTERNATIONAL TREATIES: WIPO (WORLD INTELLECTUAL PROPERTY ORGANIZATION)
--------------------------------------------------------------------------------
Core Treaties in Cyber Context:
  1. WIPO Copyright Treaty (WCT): Protects computer programs as literary works and database arrangements.
  2. WIPO Performances and Phonograms Treaty (WPPT): Protects digital sound recordings.
  3. Madrid System: International registration of trademarks.
  4. Patent Cooperation Treaty (PCT): Unified patent filing across member states.
  5. UDRP (Uniform Domain-Name Dispute-Resolution Policy): Resolves cybersquatting disputes.

6. SECTION E: HIGH-SCORING EXAM STRATEGY & SCORING TIPS
================================================================================

1. THE "COMPLIANCE & LEGAL" ADVANTAGE:
   • HIPAA & SOX requirements appear in almost every single paper. Prepare exact 3-pillar points (Administrative, Physical, Technical) to secure full 10 marks easily.
   • IT Act 2000: Always quote exact sections (Sec 43, 65, 66, 66C, 66D, 67) for top-bracket marks.

2. TECHNICAL ATTACK ANSWER STRUCTURING:
   • Buffer Overflow: Always draw the Stack Memory diagram showing Buffer -> Saved EBP -> Return Address (EIP).
   • SQL Injection: Write the exact SQL string (e.g. `' OR 1=1 --`) and the corresponding parameterized Prepared Statement solution in code.

3. ANSWERING SHORT NOTES (QUESTION 6):
   • Short notes in CS&L almost always feature: (1) Buffer Overflow, (2) HIPAA/SOX, (3) DoS/Botnets, (4) Vishing/Social Engineering.
